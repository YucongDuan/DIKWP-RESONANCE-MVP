# DIKWP-RESONANCE MVP

Created by Yucong Duan (段玉聪).

Reciprocal Energy-bounded Semantic Ontology Negotiation and Adaptive Networked Communication Evolution

跨生命—跨文明沟通演化与能量—信息—意义转换系统。

## 核心判断

沟通不是把意义装入信号后搬运。它是在能量、噪声、时延、身体、生态和制度边界下，通过可验证的相互干预，共同构造共享因果空间。高带宽只能提高符号可区分性，不能自动产生共同指称、善意、同意或意识。

## 运行

```bash
cd DIKWP_RESONANCE_MVP
PYTHONPATH=src python -m dikwp_resonance.cli --trials 12000 --seed 7152026
PYTHONPATH=src pytest -q
```

## 输出

- `outputs/communication_assessments.json/csv`：十类跨实体沟通评估；
- `outputs/forecast_summary.json`：2026—2200合成预测；
- `outputs/forecast_contracts.json`：可结算问题与行动门；
- `outputs/demo_dikwp_packet.json`：证明携带型消息包；
- `outputs/dashboard.html`：离线仪表盘；
- `RUN_PROOF.json` 与 `MANIFEST.sha256`：运行和完整性证明。

## Q0—Q9

Q0未区分耦合；Q1可检测通量；Q2条件性信号；Q3稳定代码；Q4共同指称；Q5因果模型交换；Q6目的与边界协商；Q7互惠理解；Q8身份与制度互操作；Q9共生元协议。

## 重要限制

所有数据和预测均为合成原型。Q等级不证明意识、人格、道德地位或善意。系统不得自动发送星际回应，也不得把适应性反应自动解释为同意。
